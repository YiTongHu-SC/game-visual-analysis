# 分析框架：从外观到关系

来源基线：GVF 0.2.0。12 域是检查入口，不是必须填满的报告目录，也不是互斥的素材分类。

## 12 域与关键问题

| 域 / 目录 ID | 观察重点 | 需要保留的区别 |
| --- | --- | --- |
| 表征与媒介 `representation` | 具象指涉、像素/绘画/纸墨等媒介观感、空间逻辑 | 世界维数、资产表示、投影、体积线索彼此独立；媒介观感不证明制作手段 |
| 造型与形体 `form` | 比例、剪影、几何简化、形状语言、夸张 | 可识别性、自然比例与细节数量不同；小尺寸下的剪影应单独看 |
| 线条与边缘 `line` | 外轮廓/内结构线、宽度、颜色、软硬、断续、角色与背景分工 | 选择圈、光晕、受光边缘不自动等于绘制轮廓；局部外缘不代表全局规则 |
| 表面与材质 `surface` | 可见纹理、笔触、光泽与材质提示、大小细节的组织 | 笔触与轮廓不同；可见光泽无法反推出 roughness、贴图或 BRDF |
| 色彩与调色板 `color` | 主色/强调色、面积与分配、冷暖/明度/色度关系、语义色 | 最终帧像素分布不等于源色板；高鲜艳感不等于某个 HSL S 值 |
| 光照与阴影 `light` | 明暗块组织、连续/分段过渡、阴影、发光、氛围深度 | 可见明暗是外观；实际光源、曝光和着色模型需要工程或明确文档 |
| 镜头与投影 `camera` | 可见观看方向、取景、屏幕占比、空间压缩、镜头跟随 | 侧向/斜俯视不证明正交投影或具体角度；镜头运动需要时间证据 |
| 构图与可读性 `composition` | 焦点、前中后景、负空间、密度梯度、遮挡、主体分离 | 全图平均对比不能代替关键对象相对邻域的辨识；静态辨识不等于操作有效 |
| 运动与动画 `motion` | 姿态、前摇/动作/恢复、节奏、重量、夸张、时间一致性 | 单帧姿态不证明动画流畅或自然；显示 FPS、动画更新率与动作速度分开 |
| 特效与反馈 `vfx` | 提示与结果的区分、信息优先级、覆盖、拖尾、命中、状态反馈 | 静帧密度只看空间占据与叠层；频率、寿命、延迟需录像/交互证据 |
| 界面与文字 `ui` | HUD 与场景关系、字号/边缘、组件形状、信息层级、状态编码 | 未显示不等于不存在；圆形、圆角矩形与胶囊不同；文字可见不等于已读清 |
| 输出与画面处理 `presentation` | 像素网格、缩放、锯齿、模糊、噪声、后期与画面稳定性 | JPG/重采样影响像素证据；文件分辨率不证明原生分辨率和输出策略 |

## 写实与风格不是一条轴

按需拆开具象可识别性、形体自然主义、材质响应、光照一致性、可见细节密度和运动自然主义。夸张形体可以具有现实材质响应；高细节不必写实；抽象几何也可以有稳定可识别的玩法符号。仅为沟通使用总体“偏写实/偏符号化”时，说明它概括的是哪些轴，不据此推算其他字段。

像素、低多边形、赛璐璐、手绘等标签用可见特征支持；题材、时代与文化语汇可作为语境，不代替形体、边缘、色彩、运动关系的分析。对不熟悉的文化或具体创作意图，区分来源说明与分析者推断。

## 对象 × 尺度

根据样本分开主体、敌人/友方、可交互物、场景、玩法特效、装饰特效、UI。用局部—资产—场景—时间—交互五种尺度检查结论是否越界。例如：

- 局部高光是硬边，不等于整个人物使用硬边，更不等于整款游戏的统一规则。
- 背景低对比、主体清晰轮廓、危险区域独占强调色，可以形成一致的功能分工。
- Boss、梦境、选中/受伤状态的例外可能服务叙事或信息，不先认定为风格错误。

有多个样本时寻找共同关系，同时保留不同状态/区域的例外。只有一个样本时写“候选风格规律”，不假定已观察到重复性。

## 关系比标签更有解释力

采用“对象对 + 属性差异 + 条件 + 作用 + 证据”的句式。例如（假设示例，并非真实游戏结论）：

> 暗背景区域中，主角的外缘比场景边缘更清晰，并用更大的亮暗差分离；这可能让主角更容易定位。亮背景区域尚未采样，需要检验此规则是否保持。

关注焦点如何竞争、环境如何托住主体、语义色是否冲突、UI 与世界是否争夺注意力，以及同一状态的视觉符号是否稳定。避免把全图风格一致理解为所有对象参数相等。

## 评价与改进

先声明目标：安静探索、快速战斗、信息密集策略等玩家任务会需要不同的层级与节奏。分别判断风格身份、形式一致性、功能辨识、时间稳定性；不合成一个无定义的“美术总分”。

有问题时沿“可见现象 → 可能机制 → 影响的任务 → 最小调整 → 对照验证”推理。多个原因都可能成立时，列最有解释力的候选和区分它们所需的证据。改色、改线宽、减少装饰、调整镜头或反馈时序，选择能检验假设的最小变化；保留当前有效的视觉身份。
