# GVF 离线框架

打开 [gvf/index.html](gvf/index.html) 即可使用。页面基线为 GVF 0.2.0，2026-11-14 从已发布的框架整理进入技能包。

这里保留完整网页和链接所需的 45 个文件：参数、术语、研究说明、5 个原创设计示例，以及四款游戏的 12 张官方发布截图和样本分析。核心脚本、数据、案例图像已内嵌首页；旁边的附件供原图、JSON、Schema 和文档链接使用。可整体复制此目录离线阅读，不需要服务器或 CDN。外部出处链接仍需网络。

页面的参数草稿仅保存在当前页面会话，刷新或关闭前请导出；导出结果不是完整的生产设计 profile，也不代表视觉质量验收。

2026-11-14 更新：可见差异改为猫咪法师的四组三档单变量对照，包含极粗外描边、强羽化、轮廓起伏与纹理数量变化。各档共用同一母图；纹理组附固定倍率局部放大。具体控制条件见[教学图说明](gvf/index.html#reading/tool-calibration-atlas)。

## 维护

`gvf/` 是本技能负责分发的固定离线快照，不自动跟随线上站点。原框架的研究源与构建工具单独维护，不是安装依赖。包内 [manifest.json](manifest.json) 记录全部网页文件的原字节哈希与来源版本；更新内容后重新核对文件、相对链接、嵌入数据和截图归属，再刷新清单。不要只重算哈希来掩盖来源不明的变化。

离线网页和技能的三个参数/术语/来源快照应保持同一框架版本。浏览页面不会运行原研究库中的生产校验或维护脚本，页面中相关命令是方法说明。
